성경읽기 - 바이블타임 개인정보처리방침

시행일: 2026년 9월 24일 (이전 버전: 2026년 2월 20일)

알파카앤체리스튜디오(이하 "회사")는 "성경읽기 - 바이블타임"(이하 "앱") 서비스 제공과 관련하여 이용자의 개인정보를 어떻게 처리하는지 아래와 같이 안내드립니다.

1. 수집하는 정보

앱은 다음과 같은 정보를 수집합니다:

  • 익명 사용자 ID: Firebase 익명 인증을 통해 자동 생성됩니다. 이름, 이메일 등 개인 식별 정보는 수집하지 않습니다.
  • 성경 읽기 진도 데이터: 사용자가 체크한 성경 읽기 기록 (Firebase Firestore에 저장)
  • 날짜별 읽은 기록: 어느 날 어떤 장을 읽었는지 (여정 탭 달력 표시용, 기기 및 Firebase Firestore에 저장)
  • 함께읽기 묵상 글: 사용자가 직접 작성한 묵상 글과 해당 성경 장·절, 작성 시각 (Firebase Firestore에 저장)
  • 익명 닉네임: 앱이 자동으로 만든 닉네임(예: 베드로2482). 사용자가 직접 입력하는 이름은 없습니다.
  • 신고 내용: 사용자가 신고한 글과 신고 시각 (부적절한 글 관리 목적)
  • 읽기 계획 데이터: 설정한 읽기 계획 정보 (기기 로컬 저장)
  • 알림 설정: 알림 켜기/끄기 설정 (기기 로컬 저장)
  • 광고 식별자: Google AdMob 광고 서비스 제공을 위해 기기의 광고 ID가 사용될 수 있습니다.

2. 정보 수집 및 이용 목적

  • 성경 읽기 진도 저장 및 기기 간 동기화
  • 함께읽기: 같은 장을 읽은 다른 사용자에게 묵상 글을 닉네임과 함께 보여주기
  • 부적절한 글 신고 접수 및 조치
  • 읽기 계획 계산 및 알림 서비스 제공
  • 오프라인 환경에서의 서비스 제공
  • 맞춤형 광고 서비스 제공 (Google AdMob)

3. 제3자 서비스 이용

앱은 다음 제3자 서비스를 이용하며, 각 서비스의 개인정보처리방침이 적용됩니다:

  • Google Firebase (Firebase Authentication, Cloud Firestore)
    용도: 익명 로그인, 읽기 진도·묵상 글·닉네임 저장
    방침: https://firebase.google.com/support/privacy
  • Google AdMob
    용도: 광고 서비스 제공
    방침: https://policies.google.com/privacy

4. 데이터 저장 및 보안

  • 읽기 진도 데이터는 Google Firebase 서버에 암호화되어 저장됩니다.
  • 읽기 계획, 알림 설정은 사용자의 기기 내에만 저장됩니다.
  • 수집된 데이터는 서비스 제공 목적 이외에 사용되지 않습니다.

4-1. 함께읽기 (사용자가 작성한 글)

  • 함께읽기에 쓴 묵상 글은 해당 장을 읽은 다른 사용자에게 닉네임과 함께 공개됩니다. 이름·연락처 등 개인정보는 적지 말아 주세요.
  • 처음 글을 저장할 때 「함께읽기 약속」(존중·개인정보 금지·신고 시 조치)에 동의해야 글을 올릴 수 있습니다.
  • 욕설 등 부적절한 표현이 포함된 글은 저장되지 않으며, 다른 사용자는 글을 신고하거나 특정 사용자의 글을 숨길 수 있습니다.
  • 신고된 글은 운영자가 확인 후 삭제할 수 있습니다.
  • 내가 쓴 글은 앱에서 언제든 직접 수정·삭제할 수 있습니다.

5. 데이터 보유 및 파기

  • 로컬 데이터: 앱 삭제 시 자동 삭제
  • Firebase 데이터: 서비스 이용 기간 동안 보관, 삭제 요청 시 처리
  • 묵상 글: 사용자가 앱에서 삭제하면 즉시 삭제
  • 전체 데이터 삭제를 원하시면 아래 이메일로 앱 설정의 닉네임을 알려 주세요. 해당 계정의 진도·묵상 글·닉네임을 삭제해 드립니다.

6. 사용자 권리

사용자는 다음과 같은 권리를 가집니다:

  • 수집된 데이터 열람 요청
  • 데이터 삭제 요청
  • 광고 개인화 거부 (기기 설정에서 변경 가능)

요청은 아래 연락처로 문의해 주세요.

7. 필수 권한

  • 알림 권한: 성경 읽기 알림 발송을 위해 필요
  • 인터넷 권한: Firebase 데이터 동기화 및 광고 서비스를 위해 필요
